
# CareerNexus Database Infrastructure

This repository houses the database configuration for the CareerNexus project. The system is containerized using Docker to ensure a consistent environment for all team members.

### Connection Details
To connect your application or DBeaver to the database, use the following:

* Host/IP Address: 192.168.200.56
* Port: 3306
* Database Name: careernexus_db
* Username: root
* Password: CareerNexPass32

### Team Workflow
* Database Management: The database is running as a Docker container.
* Logs & Troubleshooting: If you encounter connection issues, you can check the server logs by running the command: sudo docker compose logs.
* Environment: This is a live, shared production-like environment for the team. Please coordinate before performing any major schema changes or dropping tables.
