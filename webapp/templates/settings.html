Setting up Ollama on the Windows PC — quick version

  1. Install Ollama from ollama.com/download/windows, then ollama pull qwen3:32b (or your model of choice).
  2. Set the system environment variable OLLAMA_HOST to 0.0.0.0 and restart Ollama — by default it only listens on localhost, so nothing else on the network can reach it.
  3. Allow inbound TCP 11434 through Windows Defender Firewall (Private networks only).
  4. Give the PC a static IP or DHCP reservation, enter it above, and hit Test connection.

Full walkthrough with PowerShell commands, power-settings advice, and troubleshooting: docs/OLLAMA_SETUP.md in the repository. Keep the server LAN-only — Ollama has no authentication.
